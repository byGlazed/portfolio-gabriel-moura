# Portfólio - Gabriel Moura Silva

Meu portfólio pessoal, feito para apresentar quem eu sou, os projetos em que estou trabalhando e como falar comigo. Sou estudante de Desenvolvimento de Software Multiplataforma na Fatec Diadema, com interesse em Back-End e Cibersegurança.

## Site publicado

https://byglazed.github.io/portfolio-gabriel-moura/

## Seções

- **Sobre mim:** apresentação e foto.
- **Projetos:** [Adivinhe o Filme](https://github.com/byGlazed/adivinhe-o-filme) e [Spotify Pessoal](https://github.com/byGlazed/spotify-pessoal), com as tecnologias de cada um e link para o repositório.
- **Contato:** e-mail, LinkedIn e GitHub.

## Tecnologias usadas

- HTML5
- CSS3 (Grid, Flexbox e animação em CSS)
- Google Fonts (Bricolage Grotesque, Instrument Sans e JetBrains Mono)
- Git e GitHub
- GitHub Pages (publicação)

## Como foi desenvolvido

Cada parte do site foi feita em uma branch própria, com pelo menos 2 commits, e incorporada à `main` por Pull Request:

- `feature/pagina-inicial`: apresentação e foto
- `feature/projetos`: lista de projetos com links
- `feature/contato`: e-mail, LinkedIn e GitHub
- `feature/estilizacao`: novo visual da página
